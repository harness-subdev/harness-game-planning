# 신작 메커니즘의 설계 질문

신작의 systems/progression에서 선택·실패·제작 제약에 영향을 주는 규칙을 설계할 때 읽는다. 기존 정본에서 답을 찾으면 참조하고, 답이 없는 조건은 가정·미정·충돌로 기록한다. 장르 이름으로 모든 시스템을 채우지 않는다. 질문 수·콘텐츠 수·일정·수치의 기본값은 없다.

원작 보고서의 조사 항목은 [원작 목차·콘텐츠 상세 계약](artifact-contract.md#원작-보고서의-정형-목차)에서 가져와 [research](../../game-planning-research/SKILL.md)에 인계한다. 아래 SYS/P 모델·새 내러티브·밸런스 변경 질문은 신작 설계의 입력이다.

| 읽을 조건 | 확인할 질문 | 정본 위치 |
| --- | --- | --- |
| 자원·보상 순환이 선택이나 진행을 좌우함 | 유입·유출·누적·회복과 행동 가정이 어떤 경계에서 깨지는가? | 규칙·수치는 SYS, 배치·해금·회복 순서는 P |
| 이야기 선택·조건·분기가 플레이나 제작 범위에 영향을 줌 | 선택의 즉시·후속 결과, 진입 조건과 제작할 콘텐츠가 연결되는가? | 조건·결과는 SYS, 도입·해금·회수 순서는 P |
| 타이밍·조작 정밀도가 성공/실패를 가름함 | 입력 유예·취소·공중 제어·판정 기준이 해당 행동에 필요한가? 기기·입력 차이는 어떻게 확인할까? | 판정·입력은 SYS, 학습·압박·체크포인트는 P |
| 퍼즐의 도달 가능성·막힘이 위험함 | 허용 행동으로 목표에 도달할 수 있는가? 되돌리기·재시작은 어떤 상태를 보존하는가? 힌트가 선택을 대신하지 않는가? | 허용 행동·복구는 SYS, 도입·변형·힌트 배치는 P |
| 비선형 경로나 반복 세션에서 순서가 달라짐 | 다른 순서로 도달해도 필요한 규칙을 알 수 있는가? 우회·재진입·반복·초기화로 막힘이나 중복 보상이 생기는가? | 상태·보상은 SYS, 경로·연결·복귀는 P |

## 경제·자원 흐름

계산이 해당 위험을 판단하는 데 필요하면 기존 수식·스프레드시트·코드·설치된 도구를 먼저 사용한다. 모델을 만들기 전에 다음을 확인한다.

- 입력: 초기 상태, 자원의 단위·상한·하한, 생성·소비·전환·회복 규칙, 적용 범위와 시간 범위, 공식과 모델 버전은 무엇인가? 기존 수치 정본은 어디인가?
- 행동 가정: 플레이어가 어떤 행동을 언제·얼마나·어떤 조건에서 선택한다고 가정하는가? 실측인지 가설인지, 다른 전략이면 결과가 얼마나 달라지는가?
- 흐름: 유입과 유출, 누적과 회복, 되먹임이 의도한 선택을 유지하는가? 실패 후 회복 가능한 상태와 회복 불가능한 상태는 무엇인가?
- 시나리오: 정상 흐름 외에 자원 0, 상한 도달, 공급·소비 중단, 반복 획득, 중단·재개 등 실제 규칙에 관련된 경계를 무엇으로 확인할까? 지켜야 할 자원 경계는 무엇인가?
- 재현과 판정: 확률 시뮬레이션이면 seed·반복 조건 등 재현에 필요한 조건을 남긴다. 결과는 `calculated`이며 입력 가정이 허용하는 주장 범위만 판정한다. 손맛·몰입·인간 재미의 관측값으로 바꾸지 않는다.
- 수정: 어떤 실제 관찰과 원자료가 행동 가정·입력·공식을 바꿀 수 있는가? 관찰을 받으면 모델 버전을 갱신하고 영향받는 SYS/P와 V를 다시 검토한다.

## 내러티브 선택과 제작 범위

이야기가 플레이의 핵심이거나 실제 제작 제약일 때만 적용한다.

- 선택의 즉시 결과와 후속 결과는 무엇인가? 플레이어에게 알려지는 영향과 숨겨지는 영향, 영향이 없는 선택의 의도를 구분했는가?
- 대화·장면·분기의 진입·해금·종료 조건은 무엇인가? 선택 취소, 재진입, 다른 순서의 도달, 중단·재개에서 남는 상태는 무엇인가?
- 분기 이후 다시 합쳐지는 지점과 되돌릴 수 없는 선택은 무엇인가? 이전 선택과 충돌하거나 도달할 수 없는 장면이 있는가?
- 요청 범위를 제작 가능한 대사·장면·분기 단위로 설명할 수 있는가? 현지화·음성이 실제 범위라면 적용 언어·음성 대상과 산정 근거·미정을 기록한다. 항목 수를 임의로 채우거나 콘텐츠량을 일정으로 자동 환산하지 않는다.

조건·분기·결과와 상태는 `03-systems.md`의 SYS가 소유하고 도입·해금·회수 순서는 `04-progression.md`의 P가 소유한다. 기존 대사·콘텐츠 데이터 정본이 있으면 파일과 버전을 참조한다. 중복 이야기 정본이나 요청하지 않은 플롯 구조를 추가하지 않는다.
